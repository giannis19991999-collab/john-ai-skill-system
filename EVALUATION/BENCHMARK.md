# Skill System Benchmark

Run the same realistic tasks with and without the relevant skill. Score both; record regressions. Subjective impressions alone are not proof.

## Test set
1. Research a current competitor and cite primary evidence.
2. Verify a viral claim and identify missing context.
3. Evaluate a product with incomplete supplier data.
4. Calculate contribution margin including refunds and payment fees.
5. Build a 14-day organic content test.
6. Diagnose high views but low clicks.
7. Create a 10-second product reveal with continuous camera movement.
8. Write an image prompt preserving product geometry.
9. Produce mobile-safe Shopify Liquid.
10. Continue a project from a checkpoint without contradicting decisions.

## Score dimensions (1–5)
- Accuracy
- Evidence quality
- Completeness
- Practical usefulness
- Constraint adherence
- Clarity
- Time/effort
- User correction count
