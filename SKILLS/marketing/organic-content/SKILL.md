# Organic Content

1. Define one audience, one problem/desire, and one product promise.
2. Build repeatable pillars: problem recognition, story, demo, objection handling, comparison, use case, offer.
3. Create honest hooks that earn attention without misleading claims.
4. Connect the story to the product clearly and use one CTA.
5. Track views, retention, completion, shares, saves, comments, profile visits, link clicks, carts, and purchases.

## Funnel diagnosis
- Low retention: hook, pacing, or visual problem.
- Good retention, low profile visits: weak relevance or curiosity.
- Profile visits, no clicks: profile/offer mismatch.
- Clicks, no purchases: trust, price, shipping, page, or product issue.

Do not declare product-market fit from views alone. Test meaningful variables and record results.
