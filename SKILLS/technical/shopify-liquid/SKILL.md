# Shopify Liquid

1. Identify theme/version and exact page or section.
2. Inspect relevant existing code before replacing anything.
3. Prefer the smallest isolated change.
4. State exact insertion location and whether code replaces or supplements existing code.
5. Follow Shopify Liquid conventions; do not assume theme internals.
6. Consider mobile layout, accessibility, performance, and theme editor compatibility.
7. Protect secrets and customer data.
8. Provide rollback and testing steps.

Include complete code where practical. Never claim a live-store change was applied unless a connected tool confirms it.
