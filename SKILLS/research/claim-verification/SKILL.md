# Claim Verification

1. Rewrite the claim precisely.
2. Identify claim type and relevant context/date.
3. Find the most authoritative primary source available.
4. Seek independent corroboration and credible disagreement.
5. Check whether the source actually supports the wording.
6. Rate Supported / Partly supported / Misleading / Unsupported / False / Unclear.
7. Explain the reasoning plainly and disclose uncertainty.

For religious claims, distinguish canonical text, church tradition, patristic interpretation, and modern opinion. Do not present a personal interpretation as official doctrine.
