# Skill Creator

## Build
1. Define the recurring task and failure mode the skill should prevent.
2. Write a clear name and trigger description.
3. Define trigger and non-trigger conditions.
4. Specify workflow, inputs, outputs, constraints, and quality checks.
5. Keep the skill focused; split unrelated workflows.

## Test
- Create at least three realistic prompts.
- Compare baseline answers with skill-assisted answers.
- Score accuracy, completeness, usefulness, consistency, time, and correction count.
- Record regressions as well as improvements.
- Revise only when tests support the change.

## Maintain
Version and date the skill. Keep a changelog. Remove stale rules. Never claim improvement without comparative evidence.
