# Personal AI Skill System

A ChatGPT-first library of reusable workflows for research, e-commerce, organic marketing, AI video production, Shopify development, and long-running projects.

## Start here
1. Read [ChatGPT Setup](CHATGPT_SETUP.md).
2. Copy [Project Instructions](CHATGPT_PROJECT_INSTRUCTIONS.md) into your ChatGPT Project instructions.
3. Add [Core Rules](CORE/CORE_RULES.md) and [Skill Router](ROUTER/ALL_SKILLS.md) as Project sources.
4. Add only the specialist skills relevant to that Project.

## Important
This repository is storage and version control. It does not train a model or automatically install every skill into ChatGPT. Use the setup guide to make the instructions available in a ChatGPT Project.

## Architecture
- CORE: truth, critical thinking, execution standards.
- ROUTER: selects the smallest relevant skill set.
- SKILLS: focused specialist workflows.
- PROJECTS: checkpoints and persistent project state.
- TEMPLATES: repeatable briefs and scorecards.
- EVALUATION: benchmark skills against a baseline.

## Principles
Accuracy before confidence. Facts separate from assumptions. Practical tests before scaling. No fabricated evidence, testimonials, metrics, or completed actions.
